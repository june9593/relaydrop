# Security policy

For the public release, report suspected vulnerabilities through
[GitHub Private Vulnerability Reporting](https://github.com/june9593/relaydrop-support/security/advisories/new).
The dedicated public support repository accepts private reports. A GitHub
account is required. Do not publish access tokens, personal file
contents, preauthenticated OneDrive URLs, or account information in an issue.

The current security architecture, limitations, and release requirements are
documented in [docs/SECURITY.md](docs/SECURITY.md). The repeatable release gate is
documented in [docs/RELEASE_SECURITY.md](docs/RELEASE_SECURITY.md).
