# RelayDrop support

## General support

For installation problems, reproducible bugs, and feature requests, use the
[GitHub issue form](https://github.com/june9593/relaydrop-support/issues/new/choose).

Before opening an issue, remove Microsoft account identifiers, access tokens,
private notes, file names, preauthenticated OneDrive links, screenshots of
personal content, and any other sensitive information.

## Security reports

Do not report vulnerabilities in a public issue. Use
[GitHub Private Vulnerability Reporting](https://github.com/june9593/relaydrop-support/security/advisories/new)
so the report and follow-up remain private. This form is hosted in the
dedicated public support repository. A GitHub account is required; the
RelayDrop source repository can remain private.

## Microsoft account and OneDrive support

RelayDrop cannot reset a Microsoft password, restore a Microsoft account, or
override OneDrive retention and recycle-bin policies. Use Microsoft's official
account and OneDrive support channels for those platform-level requests.
