# Report a security vulnerability

Please use [GitHub Private Vulnerability Reporting](https://github.com/june9593/relaydrop-support/security/advisories/new)
for suspected vulnerabilities in the RelayDrop browser extension or companion
web app. A GitHub account is required. Reports are private to the reporter and
the people granted access to the advisory; they are not public GitHub issues.

Include the RelayDrop version, browser and operating system versions, a concise
description of the impact, and reproduction steps using harmless sample data.
Do not send passwords, live tokens, preauthenticated OneDrive download links,
or other people's private content. Ask for a safe transfer method if additional
material is needed.

Test only your own accounts, devices, and files, or environments for which you
have explicit permission. Avoid disrupting other users or Microsoft services.
This project does not offer a paid bug bounty or a guaranteed response time.

The latest available RelayDrop release is the focus of security fixes. The
maintainer will review reports and coordinate any disclosure through the private
advisory. For ordinary usage problems, use the public issue form instead.
