RelayDrop

Privacy

Your content stays in your Microsoft account.

Effective September 7, 2026

What RelayDrop handles

RelayDrop may process your Microsoft account name, username, and account identifier, plus notes, links, and files that you choose to send.

Where data goes

RelayDrop signs you in through Microsoft identity and sends content directly to Microsoft Graph. Your content is stored in your own RelayDrop OneDrive App Folder. RelayDrop does not operate an application content server or database and does not receive a copy of that content.

The static web host may process ordinary connection data such as IP address, user agent, request time, and requested asset according to the hosting provider's terms.

Data stored on this device

The extension stores access tokens in session-only extension storage. It may retain an account hint, appearance and refresh settings, a bounded recent-item cache, and browser download identifiers locally. Logging out clears RelayDrop authentication state and the recent-item cache. Appearance and refresh settings, download-tracking records, and downloaded files remain until you clear or delete them.

The web app stores Microsoft authentication state and your appearance preference in browser storage. It does not persist file bodies or a feed cache in browser storage.

In the extension, an expired Microsoft session or a temporary connection failure leaves cached items available until you explicitly log out. The cache may include OneDrive item identifiers and version tags to avoid downloading unchanged details again. It contains no file bodies or temporary download links and does not authorize remote access.

Sharing and permissions

RelayDrop does not sell personal data, use it for advertising, or share it with data brokers. Data is sent only to Microsoft services needed for sign-in and the OneDrive actions you request.

RelayDrop requests Files.ReadWrite.AppFolder, limiting Microsoft Graph access to its dedicated application folder. The extension does not request browsing history, active-page content, arbitrary local-file access, or native messaging.

Retention and deletion

OneDrive content remains until you remove it through RelayDrop or OneDrive. Microsoft recycle-bin, retention, or backup policies may preserve recoverable copies. You can remove device-local data by logging out, clearing browser storage, uninstalling the extension, or deleting downloaded files.

Support reports

If you choose to request help through GitHub, GitHub stores the report under its terms and privacy policy, and the maintainer can read what you submit. Ordinary issues are public. Private vulnerability reports are visible to the reporter and people granted access to the advisory. Do not include passwords, live tokens, or personal file contents.

Security reports

Use GitHub Private Vulnerability Reporting. Do not include personal file contents in a public issue. General help is available on the support page.
