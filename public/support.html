Support and security reporting

General support

For installation problems, reproducible bugs, and feature requests, use the RelayDrop GitHub issue form. Remove account identifiers, tokens, private notes, file names, preauthenticated OneDrive links, and screenshots of personal content before posting.

Open the support issue form

Security reports

Do not report a vulnerability in a public issue. The dedicated public support repository provides GitHub Private Vulnerability Reporting. Reports and follow-up are private to the reporter and people granted access to the advisory. A GitHub account is required.

Report a vulnerability privately

Microsoft account and OneDrive support

RelayDrop cannot reset a Microsoft password, restore an account, or override OneDrive retention and recycle-bin policies. Use Microsoft's official support channels for those platform-level requests.
